# 🚜 AgriShare - Agricultural Machinery Management & Resource Sharing System

A modern, farmer-friendly digital marketplace for rural agricultural equipment sharing and rental (Tractors, Combine Harvesters, Power Tillers, Drone Sprayers, Cultivators, Water Pumps).

Developed as part of the **VVIT CSE Community Service Project (CSP) - Batch 12** under the guidance of **Dr. Mohammad Shareef**.

---

## 🌟 Key Features

1. **E-Commerce Card Grid & Quick Proximity Ordering**:
   - Machinery cards automatically sorted by **proximity / shortest distance** from the farmer's current GPS location.
   - Transparent rates per Hour (₹/hr), per Day (₹/day), and per Acre (₹/acre).
2. **Direct 1-Click Action Buttons**:
   - 📞 **Direct Call Button**: One-tap phone dialer (`+918978112802`).
   - 💬 **WhatsApp Button**: Opens customized WhatsApp pre-filled chat with machinery name and farmer location.
3. **🎙️ Voice-to-Text Input (Speech Recognition)**:
   - Voice dictation on search bar, owner registration, equipment name, specs, price, and description fields with visual pulse animation.
4. **📍 GPS Geolocation & Haversine Distance Engine**:
   - Auto-detects GPS coordinates or selects from Andhra Pradesh agricultural hubs (Guntur, Vijayawada, Tenali, Amaravati, Mangalagiri, Eluru, etc.).
5. **🌾 "Rent Out Equipment" (Lender / Host Flow)**:
   - Simple 3-step listing modal for farmers to rent out their idle tractors/tools.
   - Numeric keypad for phone number, multi-photo uploads, and camera snaps.
6. **🔍 Full Technical Specifications & Cost Estimator**:
   - Engine HP, fuel policy, operator availability, insurance validity, registration numbers, and interactive rental duration price calculator.

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

## 🌐 Deploying to Vercel

```bash
# Deploy with Vercel CLI or via GitHub integration
npx vercel
```
